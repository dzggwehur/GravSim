Controls:
W,A,S,D - movement

Esc - Lock or unlock mouse

K - Track object

Scroll wheel - Increase/decrease camera speed in free camera OR camera distance in track camera

Mouse - When unlocked, moves camera

P - Pause/unpause simulation

Do not judge by raymathDouble.h and CameraAdvanced.h alongside files in "include"; these are modified Raylib classes to achieve the purpose of the project.
